The Gap

What the book promised vs what you actually filled.

Each cell shows a venue's realized fill cost in bps, with the gap in parentheses. Realized is what a clip of that size actually filled at vs the mid; advertised is what walking the order book for that size implied; the gap is realized minus advertised, so a positive gap means the venue filled worse than its book promised. The gap is floored at zero: a venue can't truly fill better than the book that existed before the trade, so any sub-zero value (book-age noise) shows as 0. This is execution quality only. Fees and funding are added in "Cost to run a position" below. Cheapest realized in bold. fl = Pacifica book feed-limited (realized shown, not gap).

Methodology & confidence

What's measured, how, and where the seams are.

A single trade usually fills in many small pieces; before measuring its cost we group those pieces back into the one order the trader actually sent. How precisely we can do that depends on what each venue publishes, shown in the table below. We also slice the data into 2-hour windows: a window is "clean" if no feed disconnect or data gap was detected during it, and windows with a gap are dropped from every number above, so a brief outage is never mistaken for a real reading. The last column shows each venue's share of clean windows, i.e. how reliably we captured its data.
